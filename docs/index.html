growthmap

Reverse-engineer how an app is marketed and distributed.

  1. Give it an app.
  2. It reads the app's own pages, their archive dates, and where the app is discussed, filmed, stored and hired.
  3. It comes back with the channels, the dated moves, the positioning, and plays that must cite what it saw.

The honesty rule

Every claim is Seen, with a link, or Inferred, with the Seen records it stands on. Nothing else is printed.

SEENs4

Homepage first seen in the archive on 2019-07-22.

link: web.archive.org/web/20190722082333/https://plausible.io/

INFERREDi1

Positioning: the homepage leads with "Plausible is a lightweight and open-source Google Analytics alternative."

from: s1

Seen is a solid bar, a filled tag and a link. Inferred is a dashed bar, an outlined tag and the records it stands on.

Cost

The run prints every call and the total. The base run is free and needs no key.

Bring your own agent

The plays are written by your own assistant. The tool refuses a play that cites evidence it did not see.

Install and use

Needs Node 20 or newer. No install step.

  1. Run it on one app. It writes the report.

    node bin/growthmap.js run example.com --out report

  2. Get the brief for your agent.

    node bin/growthmap.js playbook report

  3. Hand the plays back. It checks every citation.

    node bin/growthmap.js playbook report --accept plays.json
